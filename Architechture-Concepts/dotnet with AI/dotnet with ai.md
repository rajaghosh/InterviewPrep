Every few months someone asks me some version of the same question: "Where do I even start with AI as a .NET developer?"
Here's the honest answer — you don't start over. You start from exactly where you are.

Mapped it out as six stages:
1️⃣ Foundations you already have — C#, DI, async pipelines, REST APIs. This is the part everyone underestimates the value of. 
2️⃣ Core AI concepts — LLMs, prompting, embeddings, context windows. Theory before tooling. 
3️⃣ .NET AI tooling — Microsoft.Extensions.AI, Semantic Kernel, ML.NET. This is where it starts feeling like "your" stack again. 
4️⃣ Data & retrieval — vector databases, pgvector, Qdrant, RAG pipelines. 
5️⃣ Agents & orchestration — planners, tool calling, multi-step workflows. 
6️⃣ Production & scale — .NET Aspire, ONNX Runtime GenAI, observability, cost control.

None of this replaces what you know. It reuses it — DI, interfaces, and async patterns, just pointed at a new kind of dependency.

If you're a .NET developer looking at the AI space and wondering if you need to switch stacks or start from zero — you don't. Save this if it helps map out the path.
