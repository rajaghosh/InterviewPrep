Advanced Topics
Here are details for a few advanced topics in mobile system design.

---------------------------------------------------------------------------------------------------------

a. On-Device Machine Learning
    On-device machine learning (ML) runs ML models directly on the user's device rather than on a server. 
    This offers several benefits:
    - Privacy: User data doesn't need to be sent to a server.
    - Speed: Processing happens instantly without network latency.
    - Offline Functionality: ML features work even without an internet connection.
    - Frameworks: Developers use frameworks like Core ML for iOS and TensorFlow Lite for Android to integrate 
    pre-trained models into their apps.

b. Augmented & Virtual Reality
    Augmented Reality (AR) overlays digital information onto the real world, while Virtual Reality (VR) 
    creates a fully immersive, 
    computer-generated environment.
    - iOS: ARKit is Apple's framework for creating AR experiences.
    - Android: ARCore is Google's platform for building AR apps.
    - Headsets: Both AR and VR are often experienced through dedicated headsets, but mobile phones can also 
    serve as the display for simpler experiences.

c. Wearables
    Wearables are smart electronic devices worn on the body, such as smartwatches and fitness trackers. 
    Mobile apps need to be designed to communicate with these devices, often via Bluetooth.
    - iOS: The WatchKit framework is used to build apps for the Apple Watch.
    - Android: Wear OS is Google's operating system for smartwatches.

d. Foldables & Multi-Window UIs
    Modern smartphones with foldable screens and multi-window UIs present new challenges and opportunities 
    for developers.
    - Responsive Design: Apps must be able to adapt their layout to different screen sizes and aspect ratios, 
    whether the device is folded or unfolded.
    - Seamless Transitions: The app's state should be preserved when the device is folded or a window is resized.
    - Drag-and-Drop: Multi-window UIs enable new interactions like dragging and dropping content between two 
    different apps.

e. Server-Driven UI
    Server-driven UI (SDUI) allows the server to dictate the layout and components of a mobile app's screen.
    - Flexibility: Developers can change the UI without requiring an app update, providing greater agility.
    - Dynamic Content: The app can display different UIs based on user profile, A/B testing, or other 
    -side logic.
    - Implementation: The client app fetches a JSON or XML payload from the server that describes the UI, 
    and then renders it using a set of pre-defined components.

f. Cross-Platform Mobile Development
    Cross-platform mobile development involves building apps that can run on multiple operating systems (like 
    iOS and Android) from a single codebase.
    - Frameworks: Popular cross-platform frameworks include React Native, Flutter, and Xamarin.
    - Trade-offs: While this approach can save time and money, it may come with performance limitations or a 
    less "native" user experience compared to native development.

g. Internationalization
    Internationalization (i18n) is the process of designing an app so that it can be adapted to various languages 
    and regions without requiring changes to the code.
    - Localization: This is the process of adapting the app for a specific locale, which includes translating text, 
    adjusting for cultural norms, and handling different date and currency formats.
    - Support: Both iOS and Android provide robust support for internationalization and localization, with tools 
    for managing string files and adapting layouts for right-to-left languages.
