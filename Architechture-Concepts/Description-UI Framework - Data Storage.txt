Data Storage
Here are the details for various data storage options and performance optimization techniques in mobile system design.

---------------------------------------------------------------------------------------------------------

Key-Value Storage
    Key-value storage is ideal for storing small amounts of simple data like user settings and preferences. 
    It's not suitable for complex data structures or large datasets.
    - iOS: UserDefaults is the standard way to store small bits of user data. It's a simple key-value store 
    that persists across app launches.
    - Android: SharedPreferences is the traditional method for storing key-value pairs. Preferences DataStore 
    is a newer and more robust solution from Jetpack, which uses Kotlin Coroutines and Flow for asynchronous 
    data storage and provides better safety.

---------------------------------------------------------------------------------------------------------

Database
Databases are used for storing structured data that requires querying and relationships between different data points.
    - SQLite is a C-language library that implements a small, fast, self-contained, high-reliability, full-featured 
    SQL database engine. It's the most widely deployed database engine in the world.
    - Realm is an object database that provides a mobile-first, high-performance alternative to SQLite. It's 
    cross-platform and easy to use.
    - iOS: Core Data is Apple's object graph and persistence framework. It allows you to save, fetch, and manage 
    objects, and is built on top of SQLite by default.
    - Android: Room is a Jetpack persistence library that provides an abstraction layer over SQLite. It simplifies 
    database access and provides compile-time checks of SQL queries.
    - ObjectBox is another high-performance NoSQL database for mobile and IoT devices, known for its fast object 
    persistence and query capabilities.

---------------------------------------------------------------------------------------------------------

Secure Storage
For sensitive information like API tokens, passwords, and other credentials, it's crucial to use secure storage 
mechanisms provided by the OS.
    - iOS: Keychain is the secure storage solution on Apple platforms. It's a database that stores small pieces 
    of sensitive data in an encrypted container.
    - Android: EncryptedSharedPreferences and Jetpack Security are the recommended ways to store sensitive 
    key-value data securely. They use the Android KeyStore system to encrypt the data.

---------------------------------------------------------------------------------------------------------

File Storage
File storage is used for larger, unstructured data like images, audio, video, or large documents.
    - iOS provides directories like the Documents directory for user-generated content, the Library directory 
    for app-specific files, and the Caches directory for temporary data.
    - Android has similar options, including internal storage for app-private files and external storage 
    (shared storage) for files that can be accessed by other apps.

---------------------------------------------------------------------------------------------------------

Binary Storage
This is for storing data in a highly efficient, compact binary format.
    - Android: Proto DataStore is a Jetpack library that stores objects as protocol buffers, a language-agnostic, 
    fficient binary format. This is an excellent choice for storing type-safe, complex data structures.

---------------------------------------------------------------------------------------------------------

Performance & Optimization
Optimizing app performance is critical for a good user experience, battery life, and overall app health.
    a. Memory Management
        - Common Leak Sources: In iOS, common leaks often come from retain cycles in Swift (strong reference cycles) and 
        improper memory management in Objective-C. On Android, this can be due to holding a long-lived reference to a 
        Context or an Activity.
        - Leak Detection: Xcode's Instruments and Android Studio's Profiler are indispensable tools for detecting memory 
        leaks.
        - Profiling & Metrics: Regularly profiling your app helps you understand its memory usage, CPU load, and other 
        performance metrics to identify bottlenecks.

    b. CPU & Battery
        - Background Task Scheduling: Don't run intensive tasks in the background unnecessarily. Use system APIs 
        like WorkManager (Android) and BackgroundTasks (iOS) to schedule deferred work efficiently.
        - Power-Saving Modes:
            * iOS: App Nap is a feature that reduces the power consumption of background apps.
            * Android: Doze Mode is a deep sleep state that the device enters when it's stationary
            for a period, deferring most app activities to save battery.
        - Optimize Geo-Location Usage: Location services can be a huge battery drain. Use the lowest possible 
        accuracy and frequency settings you can get away with. Be mindful of when you need to be actively tracking 
        location versus just checking it periodically.

    c. Rendering & Animation
        - Smooth animations are key to a great user experience. A target of 60 frames per second (fps) is the goal. 
        Dropped frames (jank) can be caused by doing too much work on the main UI thread.
        - Android Studio's Layout Inspector and Xcode's View Debugger can help you identify overdrawing and complex 
        view hierarchies that slow down rendering.

    d. App Startup Time
        A slow app startup can frustrate users. Optimize the initialization process by deferring non-essential tasks 
        and loading only what is needed initially.

    e. App Size
        A large app size can deter users from downloading or updating. You should minimize the size of your app by:
        - Using image compression and asset catalog optimization.
        - Removing unused code and resources.
        - Using dynamic delivery features like App Bundles (Android) or on-demand resources (iOS) to download only what the user needs.
